# OXIDE HUB Android

Android WebView wrapper for the existing OXIDE HUB website.

- Loads the existing Cloudflare Pages site.
- Keeps the website UI and backend hosted as-is.
- Handles APK downloads through Android Download Manager.
- Build APK: GitHub Actions → Build OXIDE HUB APK → Run workflow / download artifact.

The website itself is not copied or modified by this Android wrapper.
